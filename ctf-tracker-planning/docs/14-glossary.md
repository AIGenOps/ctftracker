# 14. Glossary

- **CTF:** Capture The Flag cybersecurity competition.
- **CTFtime:** A website listing CTF competitions and event information.
- **Manifest V3:** Chromium extension platform and execution model.
- **Content script:** Extension code that runs in the context of permitted web pages.
- **Service worker:** Background extension component that may be suspended and restarted by the browser.
- **Host permission:** Permission allowing an extension to access pages on specified domains.
- **`chrome.storage.local`:** Extension-local storage API.
- **Alarm:** A scheduled event handled by the extension alarm API; not guaranteed to fire at an exact second.
- **Reminder category:** A rule such as 24 hours before an event starts.
- **Lifecycle:** The state of an event itself, such as upcoming, live, ended, postponed, or cancelled.
- **Participation status:** The user's relationship to an event, such as planned or registered.
- **Deduplication:** Avoiding multiple records for the same real-world event.
- **Canonical URL:** A normalized URL used to identify a resource where appropriate.
- **JSON backup:** Exported, versioned data file used for recovery or transfer.
- **Verified field:** A value the user has checked or explicitly confirmed.
